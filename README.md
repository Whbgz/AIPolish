# AIPolish - Typecho AI 一键润色插件

AIPolish 是一款专为 Typecho 博客系统开发的写作辅助插件。它可以无缝嵌入 Typecho 的文章 and 页面编辑器，提供正文一键润色、标题润色以及根据正文生成标题等功能。

本插件的开发初衷是为个人博主提供高效、自然的写作辅助。通过内置的去 AI 腔提示词和历史文风学习机制，润色后的文字能够最大程度保留博主原有的写作风格，避免千篇一律的套路感。

---

## 核心功能

### 1. 流式响应 (SSE)
基于 HTML5 Server-Sent Events (SSE) 技术，润色过程采用流式输出。文字实时逐字填入编辑器，配合字数接收统计，提供流畅的交互过程，避免长时间等待。

### 2. 一键撤销
每次润色后，如果在右侧对比中觉得效果不符合预期，点击“撤销”（或“撤销润色”）按钮即可将文本瞬间还原至润色前的原始状态。如果之前是部分选中润色，撤销时也会精准恢复选中区域。

### 3. 上下文感知
AI 润色不再是孤立的字面处理：
- **正文润色时**：插件会自动提取当前文章的标题发送给 AI 作为上下文，使其能够结合主题进行深度优化。
- **标题润色或生成时**：自动抓取正文前 1000~2000 字概要作为参考，使生成的标题更契合文章实际内容。

### 4. 历史文章文风学习
为了彻底避免“AI 腔”，插件在发起请求时，会自动从数据库提取当前作者最近发布的 3 篇文章（每篇截取前 300 字作为文风样本）喂给 AI。配合系统提示词中的“去 AI 味”指令，AI 将学习并模仿您真实的个人写作风格与句式结构。

### 5. 原生 UI 与连通性测试
- **原生适配**：按钮完全采用 Typecho 后台原生自带的 `.btn .btn-s` 样式类。未添加任何多余的装饰，能够完美适配各种后台主题（包括暗黑模式）。
- **即时测试**：在插件设置页面提供“测试连接”功能。直接读取当前表单输入的值进行一次极低消耗的迷你请求测试，验证接口和 Key 是否可用，无需频繁保存配置。

## 安装方法

1. 下载插件源码，将文件夹命名为 `AIPolish`。
2. 将 `AIPolish` 文件夹上传至 Typecho 安装目录的 `/usr/plugins/` 文件夹下。
3. 登录 Typecho 后台，进入 **控制台 -> 插件**。
4. 找到 **AIPolish** 插件，点击 **启用**。
5. 点击插件右侧的 **设置** 按钮，配置您的 API 接口信息。

---

## 插件配置

AIPolish 兼容所有遵循 OpenAI 标准的 API 接口（如 OpenAI, DeepSeek, 各种中转 API 等）：

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |
| **接口地址 (API URL)** | 服务商提供的 Chat 接口地址 | `https://api.deepseek.com/chat/completions` |
| **API Key** | 您在平台申请的 API 密钥 | `sk-xxxxxxxxxxxxxxxx` |
| **模型名称 (Model Name)** | 指定调用的模型代号 | `deepseek-chat` 或 `gpt-4o` |
| **系统提示词** | 内置的默认润色规则（可自由修改） | 规定保留 Markdown 格式、规定语气等 |

> **提示**：配置完成后，无需保存即可点击 **测试连接**。若显示连接成功并能正常返回测试结果，再点击保存即可。

---

## 注意事项

1. **Markdown 格式保护**：默认的系统提示词经过了严格的调优，能够保证文章中的图片标记（如 `![image.png][1]` 形式）、链接、加粗、代码块等 Markdown 标记不被 AI 修改或删除。
2. **局部润色**：在编辑器中，如果鼠标选中了部分文字，点击“AI 一键润色”将只润色选中部分；若未选中任何内容，则默认对整篇文章进行润色。
